mirk

A form-focused HTML/CSS kit. Fourteen components in plain Tailwind classes and one tiny shared script. No build step, no React, no web components.

mirk is violently obvious. Bevel borders that look pressable, sharp pixel typography, no invisible focus states. A deliberate callback to the UIs of the 80s and 90s, when buttons looked like buttons.

Every component is shown in light and dark on this page, side by side. By default mirk follows your visitor's OS theme. Add class="dark" or class="light" to any wrapper to force a mode.

To use mirk

  1. Make sure Tailwind v4 is loaded on your page.
  2. Paste the three blocks below into your page (once).
  3. Click copy on any component, paste it where you need it.

Drop in once

1. Tailwind v4 — in your <head>
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
2. Font + tokens — in your <head>
<style>
@font-face {
  font-family: 'Departure Mono';
  src: url('https://cdn.jsdelivr.net/npm/mirkui@1.0.0/fonts/DepartureMono-1.500/DepartureMono-Regular.woff2') format('woff2');
  font-weight: 400; font-style: normal; font-display: swap;
}
body { font-family: 'Departure Mono', ui-monospace, monospace; }

/* Light is the default. */
:root {
  --canvas: #F7F2EA; --bg: #F7F2EA; --fg: #15120e;
  --accent: #efefe5; --destructive: #d4183d;
  --focus-offset: 2px; --focus-color: #BBA288;
  --bevel-bg: #e9d3bd; --bevel-fg: #15120e;
  --bevel-tl: #f3ddc7; --bevel-br: #c2ad95;
  --bevel-hover-bg: #dfc9b3; --pill-inner-top: #efdac7;
  --input-border: #957E65; --placeholder-color: #7F7366;
  --ctrl-bg: #8C7660;
  --toggle-bg: #D7C5AE; --toggle-hi: #E5D3BB; --toggle-lo: #BFAA92;
  --mark-fg: #3F3225;
  --sortable-dot: #e2c5a6; --sortable-shadow: #c7a47f;
  --sortable-label: #231e18; --sortable-placeholder: #99826c;
  --slider-fill: #e9d3bd;
  --slider-nub-bg: #D7C5AE; --slider-nub-hi: #E5D3BB; --slider-nub-lo: #BFAA92;
  background: var(--canvas); color: var(--fg);
}

/* OS preference flips :root to dark. */
@media (prefers-color-scheme: dark) {
  :root {
    --canvas: #0B0C13; --bg: #1D1F2F; --fg: #F6F7F9;
    --accent: #232639; --destructive: #ff5566;

    --bevel-hover-bg: #232639; --pill-inner-top: #232639;
    --input-border: #6E738E; --placeholder-color: #545973;
    --ctrl-bg: #5F6582;
    --toggle-bg: #7A809F; --toggle-hi: #979CB4; --toggle-lo: #5E6587;
    --mark-fg: #E1E3EA;

    --slider-fill: #232639;
