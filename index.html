mirk

A form-focused HTML/CSS kit. Seventeen form components plus a content tier as semantic classes and one tiny shared script. No build step, no React, no web components.

mirk is violently obvious. Bevel borders that look pressable, sharp pixel typography, no invisible focus states. A deliberate callback to the UIs of the 80s and 90s, when buttons looked like buttons.

Every component is shown in light and dark on this page, side by side. By default mirk follows your visitor's OS theme. Add class="dark" or class="light" to any wrapper to force a mode.

To use mirk

  1. Drop the two tags below into your page (once).
  2. Click copy on any component, paste it where you need it.

Drop in once

1. mirk.css — in your <head>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/mirk-interface@2/mirk.css">
2. mirk.js — before </body>
<script src="https://cdn.jsdelivr.net/npm/mirk-interface@2/mirk.js"></script>
Renders fully on its own. Using Tailwind? @import "mirk-interface/mirk.css"; and utility classes override any mirk class — mirk is built for it, but never needs it.

Quick start a page

Or start from a whole page: one class on <body> gives you a centered column with mirk typography. Copy, save as an .html file, open it. A fuller version ships as starter.html in the repo.
<!doctype html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>my mirk page</title>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/mirk-interface@2/mirk.css">
</head>
<body class="mirk-page">

  <p class="mirk-eyebrow">getting started</p>
  <h1>A mirk page</h1>
  <p>Plain HTML plus mirk classes. Paste any component from this page below.</p>

  <button class="mirk-button"><span class="mirk-button__label">it works</span></button>

<script src="https://cdn.jsdelivr.net/npm/mirk-interface@2/mirk.js"></script>
</body>
</html>
