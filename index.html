mirk

A form-focused HTML/CSS kit. Fourteen components as semantic classes and one tiny shared script. No build step, no React, no web components.

mirk is violently obvious. Bevel borders that look pressable, sharp pixel typography, no invisible focus states. A deliberate callback to the UIs of the 80s and 90s, when buttons looked like buttons.

Every component is shown in light and dark on this page, side by side. By default mirk follows your visitor's OS theme. Add class="dark" or class="light" to any wrapper to force a mode.

To use mirk

  1. Drop the two tags below into your page (once).
  2. Click copy on any component, paste it where you need it.

Drop in once

1. mirk.css — in your <head>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/mirkui/mirk.css">
2. mirk.js — before </body>
<script src="https://cdn.jsdelivr.net/npm/mirkui/mirk.js"></script>
Renders fully on its own. Using Tailwind? @import "mirkui/mirk.css"; and utility classes override any mirk class — mirk is built for it, but never needs it.
