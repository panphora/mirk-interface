A mirk page

This whole page is plain HTML plus mirk classes: two CDN tags, one class on <body>, then components pasted where you need them. beta

Heads up
mirk follows your OS light/dark setting. Add class="dark" or class="light" to any wrapper to force a mode.

Why single-file apps

  • The file is the app: markup, styles, and state in one document
  • Saving is serialization, so what you see is what persists
  • No build step between an idea and a working page
